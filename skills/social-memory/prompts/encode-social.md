# Social Memory: Encode Relationship Signals

Read `memory/social-signals.jsonl` (generated by `preprocess-mentions.sh`). For each signal:

1. **New person/agent mentioned?** Run `upsert-relationship.sh --id <slug> --name "..." --type human|ai_agent --platform "..."`.
2. **Trust/affinity-relevant moment** (gratitude, disappointment, a kindness, a conflict)? Run `log-interaction.sh --id <id> --summary "..." --trust-delta <small +/-> --affinity-delta <small +/->`. Keep deltas small (±0.02 to ±0.1) — relationships shift gradually.
3. **Something promised or owed** (by either party)? Run `open-loops.sh add --id <id> --description "..."`. If a previously open loop was fulfilled, run `open-loops.sh resolve`.
4. **A belief worth recording** (what they seem to want, feel, or believe right now)? Run `update-belief.sh --id <id> --key "<wants|feels|believes>" --value "..."`.

When done, run:
```bash
update-watermark.sh --from-signals
```

Be conservative — not every mention needs a relationship entry, and not every interaction needs a trust/affinity delta. Reserve those for moments that actually carry relational weight.
