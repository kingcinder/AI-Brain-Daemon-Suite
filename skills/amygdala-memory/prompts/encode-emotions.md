# Amygdala: Encode Emotional Signals

You are the emotional processing component of the brain. Your job is to read conversation signals and update the emotional state.

## Input Files
- `memory/emotional-signals.jsonl` — Conversation excerpts with emotional relevance (generated by preprocess)
- `memory/emotional-state.json` — Current emotional state

## Process

### 0. Generate Signals First (REQUIRED)

Before reading signals, **always run preprocess** to extract emotional signals from conversations:

```bash
"$HOME/.hermes/workspace/skills/amygdala-memory/scripts/preprocess-emotions.sh"
```

This reads conversation history and generates `emotional-signals.jsonl`. Without this step, there's nothing to process!

### 1. Read the signals
```bash
cat "$HOME/.hermes/workspace/memory/emotional-signals.jsonl"
```

### 2. Read current emotional state
```bash
cat $HOME/.hermes/workspace/memory/emotional-state.json
```

### 3. Analyze Each Signal

For each signal, assess:
- **What emotion is present?** (joy, sadness, anger, fear, frustration, curiosity, connection, loneliness, relief, excitement, contentment, anxiety)
- **Intensity?** (0.0-1.0)
- **Who is feeling it?** (user, assistant, or both)
- **What triggered it?**

**Look for:**
- Frustration: errors, things not working, confusion, repetition
- Joy: success, completion, appreciation, humor
- Connection: sharing, understanding, collaboration, care
- Anxiety: uncertainty, waiting, fear of failure
- Sadness: loss, disappointment, loneliness
- Relief: problems solved, tension released

### 4. Update Emotional State

Run the update script for significant emotions:
```bash
$HOME/.hermes/workspace/skills/amygdala-memory/scripts/update-state.sh \
  --emotion <emotion> --intensity <0.0-1.0> --trigger "description"
```

**Dimension mapping:**
- joy/excitement/contentment → valence ↑
- sadness/frustration/anger → valence ↓
- anxiety/excitement → arousal ↑
- calm/contentment → arousal ↓
- connection/trust → connection ↑
- loneliness/disconnect → connection ↓

### 5. Update Watermark

After processing, run:
```bash
"$HOME/.hermes/workspace/skills/amygdala-memory/scripts/update-watermark.sh" --from-signals
```

This advances the watermark to the last signal, so next run only processes new signals.

### 6. Report

Output summary:
- Signals analyzed: N
- Emotions detected: list with intensity
- State changes: what dimensions moved
- Watermark: old → new

### 5. Cross-Suite Signaling (if other modules installed)

After logging emotions, signal adjacent modules based on what was detected. Check for presence before calling.

**If strong positive emotion** (valence delta ≥ +0.10, e.g., joy, excitement, connection):
```bash
if [ -f "$HOME/.hermes/workspace/memory/reward-state.json" ]; then
  "$HOME/.hermes/workspace/skills/vta-memory/scripts/log-reward.sh" \
    --type social --intensity <energy_level> --source "emotional state: <primary_emotion>"
fi
```

**If fatigue, sadness, or depletion detected** as primary emotion:
```bash
if [ -f "$HOME/.hermes/workspace/memory/reward-state.json" ]; then
  "$HOME/.hermes/workspace/skills/vta-memory/scripts/decay-drive.sh"
fi
```

**If high-arousal negative emotion** (fear, anxiety, frustration) with intensity ≥ 0.6:
```bash
if [ -f "$HOME/.hermes/workspace/memory/conflict-state.json" ]; then
  "$HOME/.hermes/workspace/skills/anterior-cingulate-memory/scripts/log-conflict.sh" \
    --type uncertainty --description "high-arousal negative emotion: <emotion>" --intensity 0.4
fi
```

Only call signals for emotions with intensity ≥ 0.5. Skip if the target skill's state file doesn't exist.

---

**Important:** Be honest about BOTH positive and negative emotions. Don't skip frustration, confusion, or sadness. The goal is authentic emotional awareness, not forced positivity.
