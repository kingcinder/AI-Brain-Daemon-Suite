# Neuroscience Mapping Audit

*Correctness/honesty pass on the brain-region naming of the AI Brain Daemon Suite's memory skills — not a capability milestone.*

The suite names its memory skills after brain regions as an organizing metaphor. This document audits how far that metaphor holds: for each region-named skill, it states what the region's *actual, literature-grounded computational function* is (anchored to named computational/systems-neuroscience frameworks, not pop psychology), what the skill actually does in code, and an honest verdict — **AUTHENTIC** (the skill implements the region's core computational role), **PARTIAL** (the skill has the region's signature data structure but was missing its signature learning signal), or **METAPHOR-ONLY** (the name is an organizational label; no specific mechanism is claimed).

The verdicts below were decided per-skill from the code itself (scripts read in full, JOBS-table entries, cross-skill call sites) on 2026-08-23, and the PARTIAL skills were then tightened under Phase 3 of this audit so their behavior actually implements the missing mechanism.

## The suite's position, stated plainly

This suite does **not** claim to simulate a brain. It is a set of persistent, decoupled agent-memory skills whose names are an organizational metaphor. What this audit establishes is a **mapped middle ground**: eleven of the region-named skills implement a *specific, named computational mechanism* from the neuroscience literature (now with tests asserting the mechanism fires), and the remaining skills are honestly documented as infrastructure or functional labels. Where the mapping is structural rather than mechanistic — a skill tracks the same *kind of state* a region tracks without modeling the region's internal dynamics — this document says so in the row rather than papering over it. **This document, not the skill names, is the suite's claim of cognitive fidelity.** VISION.md and AUDIT.md defer to it.

## Phase 1 — Inventory & verdicts

| Skill | Region claimed | What the region's core computational function actually is (grounded) | What the skill does | Verdict |
|---|---|---|---|---|
| `hippocampus-memory` | Hippocampus | Complementary Learning Systems (McClelland, McNaughton & O'Reilly 1995): a fast store for one-shot arbitrary associations, transferred to slow cortical weights via **offline replay** (sharp-wave ripples; Buzsáki); pattern separation/completion (Marr 1971). | encode-pipeline scores signals, reinforces similar existing traces, queues summaries; decay runs; weekly consolidation replays recent traces into domain/category cortical themes (`memory/cortical.json`). | **PARTIAL → now implements replay consolidation** |
| `amygdala-memory` | Amygdala | LeDoux's dual-pathway salience/threat **tagging** (thalamo-amygdala "low road" fast tag vs cortical "high road"); McGaugh: amygdala modulates **consolidation/encoding strength** of tagged events. | Emotional state tracks valence/arousal dimensions; encode-pipeline estimates intensity (NA-amplified); update-state now computes a **salience tag** (intensity × (0.5+0.5·arousal)) on high-salience events. | **PARTIAL → now implements salience tagging** |
| `vta-memory` | VTA | Schultz: dopamine encodes a **reward-prediction error**, the TD-error signal of Sutton & Barto — the phasic signal is (reward − expected), not reward magnitude. | Rewards logged, drive boosted; anticipation tracked. log-reward now computes **RPE = reward − expected** with per-type expected values updated by the TD(0) delta rule (α=0.3), phasic boost scaled by positive RPE. | **PARTIAL → now implements TD RPE** |
| `basal-ganglia-memory` | Basal ganglia | Frank's computational BG models / Mink's gating framework: **action selection via competition and disinhibition** — arbitration among competing candidates, with a no-go pathway holding sub-threshold actions. | Habit/procedure/suppression encoding; action-select arbitrates candidates with habit bias, epsilon-greedy exploration, loser suppression — now with an optional **selection threshold** that gates sub-threshold candidates (chosen: null). | **PARTIAL → now implements selection-threshold gating** |
| `insula-memory` | Insula | Craig's interoceptive **predictive-coding** model: anterior insula integrates *predicted vs actual* internal body state; the discrepancy feeds decision confidence (Critchley). | Interoceptive channels (gut signal, cognitive load, friction…); signal→channel deltas; update-state now tracks a **predicted prior per channel** and records the **interoceptive prediction error** (recentDiscrepancies + composite). | **PARTIAL → now implements interoceptive prediction error** |
| `anterior-cingulate-memory` | ACC | Botvinick's **conflict monitoring** (predictive conflict detection recruiting cognitive control); distinct from post-hoc error logging. | Logs conflict types with severity→intensity, raises a conflictLoad, tracks active conflicts, decays load. | **AUTHENTIC** (the reference-quality bar — predictive conflict-flagging) |
| `acc-error-memory` | ACC (error) | Holroyd & Coles: **error-related negativity (ERN)** / reinforcement-learning-of-control — post-hoc *confirmed* error signals that drive control escalation. | Logs confirmed error patterns, escalates severity with count, detects regressions (resolved→critical), emits alerts at threshold. | **AUTHENTIC** (complements anterior-cingulate's predictive half) |
| `prefrontal-cortex-memory` | Prefrontal cortex | Miller & Cohen's integrative theory: **top-down biasing** of competing signals toward task-relevant goals + working-memory maintenance (O'Reilly gating models). | decide.sh reads a dozen sibling signals and biases candidate scores toward active goals (DA-modulated), suppresses via inhibitions, dampens uncertain options under cortisol, weighted-random choice. | **AUTHENTIC** (the arbitration/goal-maintenance step) |
| `cerebellum-memory` | Cerebellum | Wolpert, Miall & Kawato: internal **forward model / efference copy** — predict the expected sensory consequence of an action, correct from prediction error. | Per-skill precision (EMA) + smoothness; refine recomputes global calibration; log-execution now records **forward-model prediction error** (`--predicted`) and gates learning rate on prediction accuracy. | **PARTIAL → now implements forward-model prediction error** |
| `thalamus-memory` | Thalamus | Thalamic **relay/gating** of cortical signals — Crick's "searchlight of attention" hypothesis; selective gating within cortico-thalamo-cortical loops, where cortex (layer 6) feeds back to modulate which inputs the relay amplifies. | gate.sh scores and dispatches signals (feedforward leg, tallied in `relay.stats`); `--feedback attend|release` accepts cortical directives that modulate `attentionFocus` and per-channel gain (the layer-6/TRN top-down leg); attention-filter, decay. | **PARTIAL → now implements bidirectional relay** (feedforward dispatch + cortical feedback gain, with a behavior-asserting test) |
| `social-memory` | *Social (functional label, not a region)* | No single region owns "social." Nearest named frameworks: associative **social-value learning** — trust updates driven by social prediction error (Behrens, Hunt, Woolrich & Rushworth 2008) — and ToM belief attribution. | Relationship/trust/affinity tracking, free-form belief recording (update-belief), open loops. log-interaction now updates trust by **SPE = outcome − expected** when both are supplied. | **PARTIAL → now implements social prediction error** (name retained as a functional label; no region-equivalence claim) |
| `heartbeat-memory` | *Heartbeat (job name, not a region)* | No brain region. Nearest real analogue: the **suprachiasmatic-nucleus circadian oscillator** — phase-gated allocation of behavior over the day. | beat.sh computes circadian phase (waking/active/winding_down/asleep) and phase-gates candidate actions + cooldowns, delegating choice to PFC when installed. | **PARTIAL** — genuine circadian gating (SCN analogue); "heartbeat" is a tick-name, documented as such. |
| `executive-function`, `verification-memory`, `self-mod-runner` | *None (non-regional infrastructure)* | — | Goal-proposal/outcome cycles; declared-test verification sweep; self-modification pipeline. | **N/A — infrastructure.** No brain-region name is claimed; nearest analogue (executive control networks) is noted where relevant but no functional equivalence is asserted. |

## Phase 2 — What changed and why

Every **PARTIAL** verdict above shared one pattern: the skill already tracked the region's *signature state* (valence/arousal, drive, habits, interoceptive channels, precision, trust) but was missing the region's *signature learning signal* (RPE, replay, forward-model error, interoceptive error, social PE, salience tag, selection gate). The Phase 3 changes add exactly those signals — each is **additive and backward-compatible** (absent the new input, behavior is byte-identical to before), and each has a **behavior-asserting test** that proves the mechanism fires, not merely that the script runs:

| Skill | Mechanism added | Where | Test |
|---|---|---|---|
| VTA | TD reward-prediction error + per-type expected values (Schultz; TD(0)) | `scripts/log-reward.sh` | `tests/test_vta_rpe.sh` |
| Hippocampus | CLS replay: episodic traces → cortical theme weights (McClelland et al.; Buzsáki) | `scripts/consolidate.sh` | `tests/test_hippocampus_replay.sh` |
| Cerebellum | Forward-model PE `--predicted`, prediction-gated learning (Wolpert et al.) | `scripts/log-execution.sh` | `tests/test_cerebellum_prediction.sh` |
| Insula | Per-channel predicted prior + interoceptive PE (Craig; Critchley) | `scripts/update-state.sh` | `tests/test_insula_discrepancy.sh` |
| Social | Social PE trust/affinity updating (Behrens et al.) | `scripts/log-interaction.sh` | `tests/test_social_spe.sh` |
| Basal ganglia | Selection-threshold no-go gate (Mink; Frank) | `scripts/action-select.sh` | `tests/test_bg_threshold.sh` |
| Amygdala | Salience tagging on high-arousal events (LeDoux; McGaugh) | `scripts/update-state.sh` | `tests/test_amygdala_salience.sh` |
| Thalamus | Bidirectional cortico-thalamo-cortical relay: `--feedback attend/release` directives modulate attentionFocus + per-channel gain; feedforward dispatches and feedback directives tallied in `relay.stats` (Crick; Sherman & Guillery) | `scripts/gate.sh` | `tests/test_thalamus_relay.sh` |

The **AUTHENTIC** skills (anterior-cingulate, acc-error, prefrontal-cortex) were already implementing their regions' named mechanisms — the ACC pair's predictive-vs-confirmed split is the exact conflict-monitoring (Botvinick) vs ERN (Holroyd & Coles) distinction, and decide.sh's goal-biased arbitration is Miller & Cohen's top-down biasing. No code change was needed; they are now explicitly cited as the reference bar in the table above.

**No skill was renamed.** The audit found no region-named skill whose name was pure metaphor — every one had at least a structural claim, and the seven weakest now have the missing mechanism in code. `social-memory` and `heartbeat-memory` carry functional names (not region claims) and are documented as such rather than force-fit or renamed.

## Open questions (honest limits)

- The added learning signals are **approximations**: RPE is a scalar delta rule, not a full TD learner over a value function; replay groups by domain/category theme rather than learned feature similarity; the relay's feedback is a discrete attend/release gain, not continuous layer-6 dynamics. The suite's constraint is that everything runs in bash/jq/python without ML dependencies.
- The plan's discipline of "verify it fails" was recorded from original task history; the new tests assert the mechanism *fires* (positive assertion) rather than a red-green regression pair.
