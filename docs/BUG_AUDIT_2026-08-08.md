# Exhaustive Bug Audit — 2026-08-08

Phase 1 of the exhaustive debugging pass: every core subsystem, the kernel, all
skill logic scripts, the deployment units, and the test suite entry points were
read in full before any fix was applied. This file is the complete list of bugs
found, in priority order. Status flips to `FIXED` as Phase 2 closes each one.

Legend: P0 = correctness/inverted logic (real breakage) · P1 = concurrency /
data-integrity · P2 = portability / stale checks · P3 = minor / doc-consistency

## P0 — correctness

| ID | File | Bug | Status |
|----|------|-----|--------|
| B1 | `core/self-mod/generate-proposals-llm.sh` (~L480) | Check-target guard is **inverted** under `set -o pipefail`: `if ! bash "$CHECK" ... \| tee /tmp/llm_check.json; then` — the pipeline's rc is `$CHECK`'s rc, so `!` flips it: a **good** proposal (check rc 0) hits the "rejected" branch and exits 1, while a **bad** proposal (check rc 1) falls through and gets **stored**. Rejection is both falsely triggered and bypassed. | FIXED |
| B2 | `core/agent-loop/tools.sh` (~L102) | `record_goal_outcome` tool calls `record-goal-outcome.sh --goal "$goal" --outcome ...` — but that script expects the `outcome` subcommand first and `--goal-description`/`--goal-id`, never `--goal`. The tool **always fails** (usage exit). Also advertises `deferred`, which the recorder doesn't accept (only success/failure). | FIXED |
| B3 | `skills/thalamus-memory/scripts/decay.sh` | The retry contract is broken: the filter `select(.retryAfter > $now)` **keeps** still-pending signals and **drops** the expired ones, and nothing ever re-injects them — so suppressed signals are permanently lost instead of "re-evaluated in the next cycle" as the header claims. Also writes with a fixed `.tmp` name and no lock. | FIXED |

## P1 — concurrency / data integrity

| ID | File | Bug | Status |
|----|------|-----|--------|
| B4 | `skills/anterior-cingulate-memory/scripts/{log-conflict,flag-attention,decay-load,resolve-conflict}.sh` | All four write `conflict-state.json` via `echo "$UPDATED" > "$STATE_FILE"` — **non-atomic truncate+write, no flock**. Concurrent writers (encode-pipeline spawn job + decay job + manual resolve) can tear the JSON or lose updates; the suite's own safe-write.sh documents exactly this race. | FIXED |
| B5 | `skills/amygdala-memory/scripts/{update-state,decay-emotion}.sh` | No flock on `emotional-state.json`; fixed `.tmp` name. update-state's emotion→dimension cascade re-invokes the script while the parent still holds no lock — concurrent daemon jobs (amygdala_encoding spawn + amygdala_decay) race. | FIXED (also amygdala update-watermark.sh — third writer, same class) |
| B6 | `skills/vta-memory/scripts/{seek,anticipate,log-reward,decay-drive,resolve-anticipation,update-watermark}.sh` | No flock on `reward-state.json`; fixed `"$STATE_FILE.tmp"` name. Multiple writers (vta_encoding spawn job, route dispatches, manual seek) collide on the same tmp file. | FIXED |
| B7 | `core/executive/propose-goals.sh` | Writes `pfc-state.json` (tmp+replace) **without** taking the `$PFC.lock` that `record-goal-outcome.sh` holds — a lost-update race between the two PFC writers (the exact race the lock exists for). | FIXED |
| B8 | `core/executive/record-goal-outcome.sh` (`defer-stale`) | Python writes PFC directly with `open(pfc_path, "w")` — non-atomic (a crash mid-write corrupts PFC), unlike every other PFC write. | FIXED |
| B9 | `skills/thalamus-memory/scripts/gate.sh` | Writes `thalamus-state.json` with fixed `"$STATE_FILE.tmp"` names and **no flock** on the state file — concurrent gate invocations (thalamus_gate + signal_dispatch jobs, or manual runs) can collide on the same tmp. | FIXED |

## Phase 2 — fix log (2026-08-08)

All 16 remaining bugs (B1–B9, B12–B18) closed; B10/B11 withdrawn as false
positives. Every fix validated with `bash -n` on all touched scripts, the full
`tests/test_*.sh` suite, and the phase harnesses that exercise the edited
scripts.

- **B1/B12** `generate-proposals-llm.sh` — check-target guard now tests the
  positive form (rc 0 = accept); hardcoded `/home/cody` model default removed
  (MODEL/HERMES_MODEL/--model or `/v1/models` are the only sources, with a
  clear error when a local model id is missing).
- **B2** `tools.sh` — `record_goal_outcome` calls `outcome --goal-description
  <desc> --outcome success|failure`; `deferred` removed from the advertised
  and validated outcome set.
- **B3** `thalamus decay.sh` — expired-retry signals are re-injected into
  `brain-signals.jsonl` (re-scored on the next gate run) instead of dropped;
  flock + `$$`-scoped tmp for the queue write.
- **B4** acc `{log-conflict,flag-attention,decay-load,resolve-conflict}.sh` —
  flock on `conflict-state.json.lock` + atomic tmp+mv.
- **B5** amygdala `{update-state,decay-emotion,update-watermark}.sh` — flock +
  atomic writes on `emotional-state.json`; update-state locks per-write and
  releases before its cascade subprocesses (deadlock-avoidance).
- **B6** vta `{seek,anticipate,log-reward,decay-drive,resolve-anticipation,
  update-watermark}.sh` — flock + `$$`-scoped tmp on `reward-state.json`;
  resolve-anticipation releases before calling log-reward/sync-motivation.
- **B7/B8** PFC writers — propose-goals takes `$PFC.lock`; defer-stale writes
  via tmp+`os.replace` (atomic, same guarantee as the outcome path).
- **B9/B17/B18** `gate.sh` — flock on `thalamus-state.json.lock`, `$$`-scoped
  tmps, background dispatch children drop the inherited lock fd, arg templates
  split via xargs (quoted values preserved), goal-overlap match is now a
  literal substring (same fix applied to attention-filter.sh).
- **B13** `install.sh` Step 4 now detects `vulkaninfo` (the kernel's primary
  VRAM path).
- **B14** `evaluate-proposal.sh` baseline outputs land in the `$BWS` sandbox
  (auto-cleaned) instead of fixed `/tmp` paths.
- **B15** `beat.sh` — `[]?` guards a missing `.projects` (no longer kills the
  heartbeat job under `set -e`).
- **B16** kernel deferral log message now states the true behavior (retry at
  the next scheduled slot).
- **B17 (follow-up)** `signal-daemon.sh`'s no-gate fallback dispatch path had
  the identical word-splitting bug — fixed with the same `xargs -n 1` split.
- **B12 (follow-up)** the no-model-id error is scoped to the local-API path
  (an explicit `--provider openrouter` keeps its `openrouter/auto` default).

### Post-review verification (2026-08-08)

- `deploy-proposal.sh` verified to have **no PFC writes** (no pfc/lock/flock
  references) — the PFC writer set is exactly {record-goal-outcome,
  propose-goals}, both now locked. B7 fully closes.
- `signal-daemon.sh` delegates to the gate (`echo "$line" | gate.sh --stdin`)
  — the gate is the single dispatch path, so decay's re-injected signals are
  re-scored once (re-suppress with +1h retry, or dispatch); no double-dispatch.
- Live smoke test: an amygdala `positive_state` signal routed to
  `log-reward.sh` with template `--source "positive emotional state"`
  arrived with the quoted value intact (reward-state recorded
  `source: "positive emotional state"`, drive 0.5→0.66) — B17 proven
  end-to-end, not just at the token level.
